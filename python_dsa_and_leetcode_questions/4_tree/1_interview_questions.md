Learn the various ways to navigate through a tree, a skill essential for understanding and manipulating BSTs.

### Breadth-First Search (BFS)

- Level-by-level traversal of the tree.

### Depth-First Search (DFS)

We will cover three DFS traversal techniques:

#### Pre-Order
- Root → Left → Right

#### In-Order
- Left → Root → Right

#### Post-Order
- Left → Right → Root
